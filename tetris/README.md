# 俄罗斯方块（Tetris）

C 语言控制台版俄罗斯方块，Windows 平台。

## 运行方式

需要 Windows 环境，用 Visual Studio 打开工程按 F5 运行。

## 操作

| 按键 | 功能 |
| ---- | ---- |
| ← / → | 左右移动 |
| ↑ | 旋转 |
| ↓ | 加速下落 |
| 空格 | 直接落地 |
| P | 暂停 |
| R | 重新开始 |
| Esc | 退出 |

## 计分规则

| 一次消除行数 | 得分 |
| ------------ | ---- |
| 1 行 | 100 |
| 2 行 | 300 |
| 3 行 | 500 |
| 4 行 | 800 |

- 每消 10 行升 1 级，等级越高下落越快
- 手动下移每格 +1 分，直落每格 +2 分

## 技术要点

- 二维数组模拟棋盘 board[20][10]
- 结构体 Game 打包游戏状态
- 7 种方块 × 4 个旋转态，启动时预计算
- 碰撞检测（含踢墙 Wall Kick）
- _kbhit + _getch 实现非阻塞键盘输入
